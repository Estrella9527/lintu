# 多人协作使用手册(多设备同步)

> 适用版本:v0.3.2+。面向运营/打标/审核同事,讲清楚"几台电脑一起干活,数据怎么流转"。

## 一句话理解

**每台电脑是自己的工作台;审核通过 = 发布给全组织。**
你在自己电脑上导入、打标、审核;一旦审核通过,这张图连同标签会自动上云;
其他电脑打开「多设备同步」开关后,会自动收到这些已发布的图和标签。

## 三个仓库的分工

| 仓库 | 放什么 | 谁能看到 |
|---|---|---|
| 你电脑的本地库 | 你导入的原图 + 所有工作中的数据(含未审核) | 只有这台电脑 |
| 云端数据库 | **已审核发布**的图的信息(标签/审核/上架状态) | 全组织(开了同步开关的电脑) |
| OSS 图片仓 | 图片文件本体(原图 + 缩略图) | 全组织 + 小程序 UGC |

## 标准协作流程(SOP)

1. **导入**:把照片导入灵图(流水线扫描 或 资产库上传)
2. **打标**:AI 自动打标 + 人工修正(资产库里改)
3. **审核**:到「审核」模块过一遍 → **通过即发布**(图 + 标签自动上云,无需任何手动操作)
4. **上架**:审核通过后「上架」→ 进入小程序 UGC 匹配池(审核+上架双闸门)
5. **其他电脑**:打开 设置 → 通用 → **多设备同步** 开关 → 30 秒内自动收到你发布的图和标签;资产库 / OSS 图库直接可见,可继续上架/下架/参与匹配

## 三条铁规

1. **打标 → 审核在同一台电脑上完成闭环**。未审核的半成品不会上云,别的电脑看不到——这是有意设计(云端只放发布稿)。
2. **按景区/目录分工,不要两台电脑同时改同一张图**。万一同时改了,以后写的为准(后写覆盖),先写的会被悄悄覆盖。
3. **别端的图在你电脑上只有"信息"没有"文件"**。浏览、看标签、上架/下架、匹配都正常(图走云端 CDN 显示);要对它做 AI 加工(重绘/超分等)请先右键「保存原图」到本地再导入。

## 开关在哪里

设置 → 通用 → 多设备同步。
- **开**:本机每 30 秒从云端拉一次别人发布的更新(首次会全量拉一遍,几分钟内完成)。
- **关**(默认):本机不收别人的数据;但你自己审核发布的内容**始终**会上云给别人。

## 常见问题

**Q: 我在 A 电脑打的标,B 电脑看不到?**
按顺序检查:① 那张图在 A 上审核通过了吗(没通过不上云)?② B 的「多设备同步」开了吗?③ 等 30 秒了吗?

**Q: OSS 图库里很多「库外」的图是什么?**
是 OSS 仓里有文件、但没有任何电脑发布过信息的图。把它「导入」后走 打标 → 审核 → 上架 流程即可转正。

**Q: 两台电脑都改了同一张图的标签怎么办?**
后保存的覆盖先保存的,不报错不提示。所以请按目录分工。(后续版本会加对账面板来发现这类冲突。)
