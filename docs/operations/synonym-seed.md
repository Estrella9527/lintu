---

## 1. 这个事是什么 / 为什么要做

### 一句话背景

UGC 用户写文案时不会用景区的"标准词"。他们会写 **"带娃来玩"**，但灵图库里的标签是 **"儿童"**；他们会写 **"傍晚拍照超美"**，但库里的标签是 **"黄昏"**。如果不告诉系统这些是一回事，匹配就找不到合适的图。

### 解决方案：同义词词典

灵图有一个「**用户口语 → 标准标签**」的映射表（叫**同义词词典**）。在做匹配前先把用户文本里的口语词替换成库里的标准词，命中率就上去了。

```
   用户输入                                        匹配召回
"带娃来玩水" ──同义词替换──▶ "带儿童来玩水域" ──▶ 命中标了 "儿童"+"水域" 的图
```

### 当前状态

- ✅ 词典系统已经建好，**已有 22 个内置词条**（详见第 3 节）
- ❌ 内置词条远远不够 — 每个景区都有自己的方言、设施别名、客群称谓
- 🎯 **目标：上线第一周补到 50+ 自定义词条**

## 5. 录入操作步骤

### 在桌面端

1. 打开灵图桌面端
2. 左侧栏点 **「匹配实验室」**
3. 切到 **「同义词」** Tab
4. 在底部输入框：
   - 左边输入「**用户口语**」（如 `娃`）
   - 右边输入「**标准标签**」（如 `儿童`）
   - 点 ➕ 添加
5. 添加成功会立即出现在上方词条列表里，**实时生效**（不用重启服务）

### 验证生效

1. 切到「匹配实验室 → 试匹配」Tab
2. 输入测试文案：`带娃来玩水`
3. 看返回结果中是否出现标了 `儿童 + 水域` 的图
4. 如果之前 0 结果，现在有结果 → 同义词生效

### 删除 / 修改

- **删除**：在词条列表里 hover 一个词条 → 右侧出现 ❌ → 点删除
- **修改**：先删除旧的，再添加新的（暂时没有"原地编辑"按钮）

## 8. 常见问题 FAQ

### Q1：标准标签的可选值在哪看？
**A**：在浏览器访问 `http://localhost:7879/api/tag-schema`，会返回所有维度（scene / facility / season / weather / angle / people / usage / style / mood / palette / theme / composition）的标准值列表。

或者：在桌面端 → 设置 → 标签体系 Tab，可视化看到全部维度。

### Q2：能加多个 alias 指向同一个 canonical 吗？
**A**：能。例如：
- 娃 → 儿童
- 小孩 → 儿童
- 仔仔 → 儿童

都加进去就行。

### Q3：能加 alias = canonical 一对多吗？
**A**：不能。每个 alias 只能对应**一个** canonical。如果"漂"既可以指漂流也可以指漂浮，需要靠语境，目前系统不支持，建议挑最高频的那个映射。

### Q4：误加了一条怎么办？
**A**：在词条列表里 hover 一下，右侧出现 ❌ 点删除即可。删除也是实时生效。

### Q5：同义词会自动同步到云端吗？
**A**：会。每次添加 / 删除后约 30 秒内同步到云端 sidecar，UGC 调匹配时立刻用上新词典。

### Q6：跟"匹配权重"是什么关系？
**A**：完全独立。同义词改的是**召回**（让正确的图被找出来），权重改的是**排序**（让高质量的图排前面）。两个都要管。

### Q7：内置词典的 22 条以后会变吗？
**A**：可能会增加（开发同步加进默认列表），但**不会减少**。你自定义的词条优先级高于内置，不会冲突。

### Q8：会不会因为同义词太多反而匹配不准？
**A**：理论上有可能（"过度泛化"），但目前 50-200 条规模完全在安全区。如果加到 500+ 条且有效果退化，再考虑做"按场景生效"的优化。
